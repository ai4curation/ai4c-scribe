1. **Definition quality matters** - Reviewers will rewrite verbose/unclear definitions
2. **Include key molecular markers** when they define the cell type
3. **Gene/protein nomenclature** - Use standard symbols (ChAT, VAChT/Slc18a3, etc.)
4. **PRs may merge incomplete** - Some feedback addressed "later" creates technical debt
