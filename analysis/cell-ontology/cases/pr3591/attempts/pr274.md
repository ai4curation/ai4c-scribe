## Summary of changes

The new subset follows the same shape as the existing `cl:added_for_HCA` subset, which is already used for the HCA-contributed term subset.

```
AnnotationAssertion(rdfs:comment cl:add_by_HRA "a subset of terms added by the Human Reference Atlas (HRA) and HuBMAP team members, used for tracking purposes.")
AnnotationAssertion(rdfs:label cl:add_by_HRA "add_by_HRA")
SubAnnotationPropertyOf(cl:add_by_HRA oboInOwl:SubsetProperty)
```

## Rationale / design notes

- **IRI**: `http://purl.obolibrary.org/obo/cl#add_by_HRA` (the `cl:` prefix), matching the convention used by `cl:added_for_HCA`, `cl:BDS_subset`, `cl:kidney_upper_slim`, etc. The local name `add_by_HRA` is taken verbatim from the issue title to avoid second-guessing the requester.
- **`SubAnnotationPropertyOf … oboInOwl:SubsetProperty`**: This is what makes the property usable as a value of `oboInOwl:inSubset` and what causes ROBOT/ODK to treat it as a subset. Same pattern as the other `cl:*` subset properties in the file.
- **`obo:IAO_0000233` (term_tracker_item)**: Links the subset back to issue #3590. Per the `CLAUDE.md` "Other metadata" section, new entities should link to the originating issue.
- **`terms:date`**: Creation date stamp, following the project convention for new entities.
- **`rdfs:comment` + `rdfs:label`**: Match the pattern used by `cl:blood_and_immune_upper_slim` and `cl:kidney_upper_slim`, which both have a date + comment + label.
