## Changes Made

### 1. Declaration of the Annotation Property
Added the declaration for the new annotation property in the Declarations section:
- `Declaration(AnnotationProperty(cl:add_by_HRA))`
- Positioned after `cl:BDS_subset` to maintain alphabetical ordering within the cl: namespace subsets

### 2. Subset Property Definition

- `SubAnnotationPropertyOf(cl:add_by_HRA oboInOwl:SubsetProperty)` - Declares this as a SubAnnotationPropertyOf the OBO standard SubsetProperty

- Added comment explaining the subset's purpose: `AnnotationAssertion(rdfs:comment cl:add_by_HRA "Terms added by HRA and HuBMAP team members")`

## Technical Details

The implementation follows the existing pattern for subset tags in the Cell Ontology, mirroring the approach used for other tracking subsets like `cl:added_for_HCA` and `cl:BDS_subset`.

The subset can now be applied to terms using the `oboInOwl:inSubset` annotation with the `http://purl.obolibrary.org/obo/cl#add_by_HRA` IRI.

## Use Case

This subset tag will enable the HRA team to systematically track which terms in the Cell Ontology have been added or contributed by HRA and HuBMAP team members, facilitating:
- Impact assessment of HRA/HuBMAP contributions
- Maintenance and version control of collaborative additions
- Data provenance tracking
