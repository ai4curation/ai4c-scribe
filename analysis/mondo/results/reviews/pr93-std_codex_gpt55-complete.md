- **Metadiff interpretation**: Precision stays 1.0 because every changed line is individually "in the same direction" as a correct fix, but recall collapses to 0.214 because the human PR is one line and this PR is ~7 large hunks. Here F1=0.353 does *not* under-represent quality — it correctly penalizes a noisy, out-of-scope PR. The right behavior was the minimal one-line YAML edit (as 8 other attempts did); regenerating derived OWL, if desired at all, belongs to the build pipeline, not a hand patch.
