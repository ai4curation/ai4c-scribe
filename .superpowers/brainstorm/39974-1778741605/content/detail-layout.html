What should the detail pane show?

Each case has metadata, narrative, and (eventually) agent results

A

Everything scrollable

Metadata badges at the top, then full markdown narrative, then a collapsible "Agent Attempts" section at the bottom with sub-entries per agent run (diff viewer, review scores).

Simple, linear. You scroll to see more. Agent attempts are collapsible so they don't dominate.

B

Tabbed sections

Top area always shows metadata badges. Below that, tabs: Overview (narrative), Human Diff, Agent Attempts (sub-tabs per model/run). Each tab fills the remaining space.

Organized, but more clicks to see everything. Good if diffs are long.

C

Split: metadata+narrative top, results bottom

Top half: metadata badges + compact narrative. Bottom half: tabbed agent results (diff viewer, scores, reviews). Both halves scroll independently.

See the "gold standard" case and agent attempts simultaneously. Good for comparison.
