How should the gallery navigation work?

Think iPhoto/Lightroom — how do you want to move through cases?

A

Grid → Detail

Landing page shows a card grid (all ontologies together or filterable). Click a card to see the full case detail with metadata, narrative, diffs, and scores. Arrow keys or prev/next to step through.

Pros

  • Quick visual scan of all 160 cases
  • Filters narrow the grid
  • Natural "gallery" feel

Cons

  • Cards need enough info to be useful at a glance
B

Sidebar List → Detail Pane

Left sidebar lists cases (grouped by ontology). Click one to see its detail in the main pane. Sidebar stays visible for quick switching.

Pros

  • Always see where you are in the list
  • Fast switching between cases
  • Good for sequential review

Cons

  • Less "gallery" feel, more "file browser"
C

Hybrid: Grid overview + Sidebar detail

Start with the grid for browsing/filtering. Clicking a card switches to sidebar+detail mode for sequential review. A "back to grid" button returns to the overview.

Pros

  • Best of both — browse and review
  • Most flexible

Cons

  • More complex to build
