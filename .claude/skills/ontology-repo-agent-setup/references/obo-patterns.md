# OBO Foundry Patterns

Common patterns for OBO Foundry ontologies using the Ontology Development Kit (ODK).

## ODK Repository Structure

```
{ontology}/
├── src/ontology/
│   ├── {ontology}-edit.owl     # Main edit file
│   ├── {ontology}-edit.obo     # OBO format (if OBO-primary)
│   ├── Makefile                # Generated by ODK
│   ├── {ontology}-odk.yaml     # ODK configuration
│   ├── imports/                # External ontology imports
│   ├── components/             # Modular pieces
│   ├── patterns/               # DOSDP patterns
│   └── reports/                # Validation reports
├── .github/workflows/          # CI workflows
├── Makefile                    # Root Makefile (calls src/ontology/)
└── run.sh                      # Docker wrapper for ODK
```

## Common ODK Make Targets

```bash
# In src/ontology/ directory:
make test           # Run basic tests
make validate       # Full validation suite
make reason         # Run reasoner
make all            # Build all release products
make refresh-imports # Update imported ontologies

# Common test targets:
make IMP=false test # Test without refreshing imports
make MIR=false test # Test without mirrors
```

## Common OBO Annotations

| Annotation | Property | Usage |
|------------|----------|-------|
| Label | rdfs:label | Human-readable name (required) |
| Definition | IAO:0000115 | Text definition (required for new terms) |
| Synonym | oboInOwl:hasExactSynonym | Exact synonym |
| Synonym | oboInOwl:hasRelatedSynonym | Related synonym |
| Synonym | oboInOwl:hasBroadSynonym | Broader synonym |
| Synonym | oboInOwl:hasNarrowSynonym | Narrower synonym |
| Database xref | oboInOwl:hasDbXref | Cross-reference |
| Comment | rdfs:comment | Editorial notes |
| Deprecated | owl:deprecated | Obsolete status |
| Replaced by | IAO:0100001 | Successor term |
| Consider | oboInOwl:consider | Alternative terms |

## Obsoletion Patterns

Standard pattern for obsoleting terms:

```
# OBO format
[Term]
id: GO:0000001
name: obsolete mitochondrion inheritance
is_obsolete: true
replaced_by: GO:0048311
comment: This term was obsoleted because it was redundant with GO:0048311.

# OWL/Manchester syntax
Class: GO_0000001
    Annotations:
        rdfs:label "obsolete mitochondrion inheritance",
        owl:deprecated true,
        IAO:0100001 GO:0048311,
        rdfs:comment "This term was obsoleted..."
```

## DOSDP Patterns

Dead Simple OWL Design Patterns (DOSDP) automate term creation:

```yaml
# Example pattern: disease_by_infectious_agent.yaml
pattern_name: disease_by_infectious_agent
classes:
  disease: MONDO:0000001
  infectious_agent: NCBITaxon:1
relations:
  disease_has_infectious_agent: RO:0001025

vars:
  disease: "'disease'"
  infectious_agent: "'infectious_agent'"

name:
  text: "%s infectious disease"
  vars:
    - infectious_agent

def:
  text: "A %s that is caused by infection with %s."
  vars:
    - disease
    - infectious_agent
```

## Common Failure Modes in OBO Ontologies

Based on analysis of AI agent PRs:

1. **Duplicate term creation** - Creating terms that already exist
2. **Wrong obsoletion pattern** - Not following standard obsolete marking
3. **Missing required annotations** - Omitting definition or label
4. **Invalid xref format** - Incorrect database prefix or ID format
5. **Hierarchy errors** - Placing terms under wrong parent
6. **ID format errors** - Using wrong prefix or non-numeric IDs

## Agent Best Practices for OBO

1. **Search before creating** - Check if term exists first
2. **Copy exact format** - Use existing terms as templates
3. **Run validation** - Always run `make test` before commit
4. **One change at a time** - Keep PRs focused
5. **Document reasoning** - Explain why changes were made
